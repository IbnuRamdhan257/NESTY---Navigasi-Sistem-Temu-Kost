# NESTY---Navigasi-Sistem-Temu-Kost
NESTY (Navigasi Sistem Temu Kost) adalah aplikasi web manajemen dan sistem temu kost berbasis PHP &amp; MySQL. Dilengkapi fitur manajemen kamar, registrasi member, pemilihan &amp; pindah kamar, upload bukti pembayaran, verifikasi admin, hingga sistem pengajuan komplain untuk memudahkan pengelolaan operasional kost secara terpusat.
